## FadenWerk — what I'm building now

**A writing studio for novelists.** Manuscript, chapters and scenes, character
records, lore, plot threads, and wiki-style links — connected in one place, with
clean Markdown and DOCX/EPUB/PDF export.

Web-first and reachable from any device, with a macOS app as a first-class offline
client: write on a flight, sync when you reconnect. Your prose stays yours — open
Markdown that round-trips losslessly, never locked in.

Try it out on [fadenwerk.sanlytech.de](https://fadenwerk.sanlytech.de)
